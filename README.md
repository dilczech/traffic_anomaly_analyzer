
Автоматизированный комплекс поиска аномалий в данных учета дорожного движения

тестовый вариант. Версия 0.1 от 08.10.26

--------------------------------------------------------------------------------
1. ОПИСАНИЕ ПРОЕКТА
--------------------------------------------------------------------------------
Проект предназначен для пакетного автоматического анализа больших объемов 
почасовых данных интенсивности и состава транспортных потоков.

Главная цель - объективный математический аудит и выявление аномальных суток 
и аномальных месяцев без субъективных предположений о причинах инцидентов.

Комплекс выполняет:
- Анализ полученных сложных Excel-файлов с несколькими участками дорог;
- Поиск дорожных заторов, аварийных спадов, всплесков и технических сбоев;
- Сравнение суточных профилей движения с типичными ритмами рабочих и выходных дней;
- Межгодовой макро-анализ месяцев (Year-over-Year, YoY);
- Автоматическую генерацию цветного Excel-реестра и графиков сравнения.

--------------------------------------------------------------------------------
2. АРХИТЕКТУРА ДЕТЕКЦИИ (3 СИСТЕМЫ ПОИСКА АНОМАЛИЙ)
--------------------------------------------------------------------------------
Алгоритм объединяет три независимые математические системы, исключающие 
взаимные «слепые зоны»:

СИСТЕМА 1: Физическая целостность и телематика (Rule-based)
- Залипание датчика (Flatline): фиксация одинаковых значений интенсивности 
  на протяжении 5+ часов подряд;
- Экстремальные заторы: падение скорости < 35 км/ч при загрузке полосы > 60%;
- Дисбаланс направлений: перекос потока (> 85% в одну сторону) в часы активности;
- Неполные сутки: учет и фиксация дней, где записано менее 24 часов.

СИСТЕМА 2: Форма суточного профиля (Pattern / Correlation-based)
- Анализ суточного ритма: сравнение фактического 24-часового вектора с медианным 
  профилем месяца для данного типа дня (будни/выходные);
- Коэффициент корреляции Пирсона: если r < 0.70 при достаточном объеме трафика, 
  день маркируется как аномальный (ночные всплески, размазанный пик).

СИСТЕМА 3: Амплитудная статистика и макро-анализ (Statistical / Distribution)
- Суточный уровень: Modified Z-score на основе робастных метрик (медиана и MAD). 
  Фиксация спадов и всплесков суточного объема (отклонения от нормы на 25-50%+);
- Месячный уровень (YoY): сопоставление одинаковых месяцев разных лет 
  (октябрь к октябрю). Выявление долгосрочных ремонтов (падение скорости > 15 км/ч), 
  структурных сдвигов грузового каркаса (изменение доли грузовиков > 8%) 
  и аномалий среднемесячной суточной интенсивности (ССИ/MADT > 25%).

3. ТРЕБОВАНИЯ И УСТАНОВКА
--------------------------------------------------------------------------------
- Python 3.8 или новее.
- Необходимые внешние библиотеки:
  * pandas
  * openpyxl
  * matplotlib
  * numpy

Установка зависимостей одной командой:
$ pip install pandas openpyxl matplotlib numpy

--------------------------------------------------------------------------------
4. ИНСТРУКЦИЯ ПО РАБОТЕ
--------------------------------------------------------------------------------
1. Поместите ваши файлы выгрузок (.xlsx или .xls) в папку `input_data/`.
   (Скрипт поддерживает работу как с одним тестовым файлом, так и с пакетом из 
   70+ файлов за весь нужный период).
2. Убедитесь, что файлы закрыты и сохранены в программе Microsoft Excel.
3. Запустите скрипт:
   $ python traffic_anomaly_analyzer.py

   Дополнительные флаги (опционально):
   --input   Путь к пользовательской папке с исходными данными (по умолчанию: ./input_data)
   --output  Путь к папке для сохранения отчетов (по умолчанию: ./reports)

   Пример:
   $ python traffic_anomaly_analyzer.py --input ./my_data --output ./my_results

--------------------------------------------------------------------------------
5. СПЕЦИФИКАЦИЯ ВХОДНЫХ ДАННЫХ
--------------------------------------------------------------------------------
Файлы Excel имеют вертикальную структуру на одном рабочем листе:
- Внутри одного файла последовательно друг под другом расположены данные 
  по 3 участкам дороги (например, км 13+650, км 70+850, км 120+400 на а/д Р-193);
- Каждый блок содержит ~744 строки (почасовые срезы за месяц) и завершается 
  строками «Итого», «Среднее», «%»;
- Строки заголовков документа, пустые разделители и служебные хвосты 
  отсекаются парсером автоматически;
- Фиксация данных происходит строго по наличию корректного таймстемпа в колонке А;
- Таблица состоит из 29 колонок:
  1. Дата/Время
  2-4. Общая интенсивность (Итого / Прямое / Обратное)
  5-25. Категории ТС (Легковые, Малые груз., Грузовые, Груз. большие, 
        Автопоезда, Автобусы, Мотоциклы)
  26-27. Скорость, км/ч (Прямое / Обратное)
  28-29. Загрузка, % (Прямое / Обратное)

--------------------------------------------------------------------------------
6. ВЫХОДНЫЕ ДАННЫЕ И РЕЗУЛЬТАТЫ
--------------------------------------------------------------------------------
По завершении работы формируются два типа артефактов:

1. Реестр `traffic_anomalies_report.xlsx`:
   - Лист «Аномальные сутки»: детальный список выявленных инцидентов 
     (Участок, Дата, Уровень критичности, Детектор, Параметр, Факт, 
     Норма, Отклонение %, Описание цифрами);
   - Лист «Аномальные месяцы (YoY)»: список периодов с макро-отклонениями 
     интенсивности, скорости и состава потока относительно многолетней нормы;
   - Цветовая дифференциация: розовый/красный цвет — критические сбои, 
     светло-желтый — умеренные аномалии.

2. Графики в папке `reports/plots/`:
   Для каждого подозрительного дня формируется 2-панельное изображение:
   - Верхняя панель: серые столбцы (медианная норма часа для данного месяца) 
     в сравнении с фактической кривой аномального дня + маркер пика расхождения;
   - Нижняя панель: фактическая скорость направления относительно нормы 
     и критической границы затора (40 км/ч).

--------------------------------------------------------------------------------
7. ВАЖНЫЕ ОСОБЕННОСТИ И ПРЕДОТВРАЩЕНИЕ СБОЕВ
--------------------------------------------------------------------------------
1. Блокировка файлов (Windows): если файл открыт в Excel во время выполнения, 
   скрипт не сможет его прочитать. Закрывайте таблицы перед запуском.
2. Работа с 1 файлом: при обработке только одного месяца анализ суток 
   выполняется полностью. На листе межгодового анализа будет выведено сообщение 
   о необходимости минимум двух лет для сравнения YoY.
3. Устойчивость к поврежденным файлам: при обнаружении битого архива или 
   нечитаемой таблицы скрипт выводит предупреждение в консоль, пропускает 
   проблемный файл и продолжает обработку оставшегося массива.
4. Очистка строковых чисел: парсер автоматически удаляет неразрывные пробелы (\xa0), 
   случайные пробелы и заменяет запятые на точки при преобразовании в числа.
